# Cómo contribuir

- Nuevos referentes: `pipeline/sites.source.mjs` (siempre con fuente y fecha).
- Nuevos patrones: `datos/rules.json` (criterio medible, explicación simple y pasos para aplicarlo).
- Curiosidades culturales: `datos/insights.json` (con fuente y nivel de evidencia; las hipótesis se marcan como tales).
- Antes de publicar: `npm run check`.
